A simple, responsive privacy policy website for applications using WhatsApp Business API.

## Features

- ✅ Responsive design
- ✅ Clean, professional styling
- ✅ WhatsApp brand colors
- ✅ Mobile-friendly layout
- ✅ Ready for GitHub Pages deployment
- ✅ Vercel deployment ready

## Deployment Instructions

### GitHub Pages Deployment

1. Create a new repository on GitHub
2. Push this code to the repository
3. Go to repository Settings
4. Scroll down to "Pages" section
5. Select source as "Deploy from a branch"
6. Choose "main" branch and "/ (root)" folder
7. Click Save
8. Your site will be available at `https://HimanshuHeda.github.io/Privacy-Policy-Whatsapp`

### Vercel Deployment

1. Go to [vercel.com](https://vercel.com)
2. Sign up/login with your GitHub account
3. Click "New Project"
4. Import your GitHub repository
5. Deploy with default settings
6. Your site will be available at a vercel.app URL
